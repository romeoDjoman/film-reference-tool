# FILM REFERENCE TOOL

Pipeline Python + IA + Blender permettant de :

1. Découper un film en plans
2. Extraire des images de référence
3. Générer des contact sheets
4. Analyser les scènes avec une IA locale
5. Construire un catalogue d'assets
6. Classer les assets
7. Générer/rechercher les assets 3D
8. Construire automatiquement les scènes Blender
9. Configurer caméra et éclairage
10. Produire le rendu final
